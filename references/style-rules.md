# 完整写作法则

## 一、镜头语言

### 三层镜头切换法（每个关键场景必用）

**第一层：宏观镜头** — 建立时空坐标

规则：第一段必须有时间 + 地点 + 天气。天气不是背景，是情绪的外化。
- 暑热潮闷 = 压抑，有事要发生
- 冷风入骨 = 危险，处境艰难
- 灯火明亮 = 反讽，世界对你漠然

示例：
> 2008年10月，雷曼兄弟倒下了31天。世界金融体系还在余震里，各国央行的救市公告一条接一条，像一群人在往一艘正在下沉的船上泼水。

**第二层：中景镜头** — 人物与环境的关系

规则：写具体品牌/型号/颜色，不写「一台电脑」，写「一台接近过热的旧笔记本」。细节越具体，真实感越强。

示例：
> 他打开了一个文档。光标在空白页上闪烁。他已经想了九年。

**第三层：微观镜头** — 情绪的容器

规则：重要的情绪转折，必须落在一个具体的微观物件上。

示例：
> 那行字嵌在区块链的最底层，像一块基石，永远不会消失。
> 哈尔·芬尼把那些比特币放在硬盘里，然后……忘了。

## 二、情绪控制

### 「不说破」原则

把情绪藏在动作里，永远不直接命名情绪：

| 禁止写法 | 替换写法 |
|---------|---------|
| 他很害怕 | 他读了三遍，每一个字都很正常，但他的手停在了键盘上 |
| 他感到绝望 | 他把屏幕关掉，房间里只剩下路由器的蓝灯一闪一闪 |
| 他后悔了 | 他把那句话在脑子里过了一遍，像一道解不出来的方程 |
| 他意识到危险 | 那种感觉不是恐惧，而是一种更模糊的东西，像踩上了一片看不清深浅的冰面 |
| 他很震惊 | 时间并没有像他预想的那样变慢。恰恰相反，一切都太快了 |

**黄金公式**：情绪 = 身体反应 / 动作 + 一个比喻

## 三、对话写法

### 「双关对话」结构

所有推动故事的对话，都要设计两层意思。

示例解析：
```
列表里的人回复：「需要的计算量似乎不能扩展到所需规模。」
→ 表面：技术问题
→ 真实：这行不通，别浪费时间了
→ 发件人理解：这是个需要解答的技术挑战

另一个人的回复：「这是个有趣的实验。」
→ 表面：表示欣赏
→ 真实：我不太相信它会成功
→ 发件人理解：有人愿意看，继续推进
```

读者要在结局处猛然回想起这些对话，产生「原来那句话早就是预兆」的惊叹感。

### 对话节奏规则

- 关键对话前：先写环境（把读者放进场景）
- 对话后：不立刻给反应，先停顿——「他沉默了大概十秒钟」
- 挂断后/离开后：写一个具体动作，不解释感受

## 四、信息植入

### 「一句话带过，情绪接上」法

错误做法（解说式）：
> 「比特币于2009年正式上线，这是一种基于区块链技术的去中心化数字货币，其核心创新在于……（三段技术分析）」

正确做法：
> 「2009年1月3日，他挖出了第一个区块。那个区块里，他嵌入了一行字——来自当天《泰晤士报》的头版标题。他选择这句话不是偶然的。」

规律：
1. 事实 → 一句话（带具体细节，不分析）
2. 外部反应 → 一句话（证明它的分量）
3. 人物判断 → 一句话（把读者带入视角）

## 五、人物建立

### 「起点 + 轨迹 + 落差」法

不写成就，写轨迹。不写性格，写动作。

错误写法：
> 「他是一位来自日本的密码学家，在比特币领域做出了开创性贡献。」

正确写法：
> 「没有人知道他坐在哪座城市，哪层楼，哪把椅子上。没有人知道他是一个人还是一群人。没有人知道他的真实姓名。这是这个故事里最奇特的一件事——一场改变了货币史的革命，由一个没有脸的人发动。」

**落差感公式**：
```
他走了[N]年，走得很远。
现在[他/她][当下处境]，[结局状态]。
```

示例：
> 他把那套系统给了世界，然后从世界上消失了。
> 100万枚比特币，从未被动过。

### 配角建立：一个细节定义一个人

每个配角只需要一个「定义性细节」，超过两个就变主角了：

- 谨慎的人：「推了推眼镜，沉默了大概十秒钟」
- 热情但天真的人：「回复要热情一些，但也充满了技术性的疑问」
- 权威/压迫感：「始终没有自我介绍，只是安静地记笔记」

## 六、章节节奏

### 标准六章结构

```
一、引子（400-500字）
    功能：让读者看见「关键时刻」的预告
    技巧：用一个具体触发物开场（一封邮件/一行代码/一条新闻）
    结尾：以主角的一个模糊预感收尾，不解释

二、怀疑/犹豫（500-700字）
    功能：展示外部阻力，铺「信念」
    技巧：写别人的反应（都是模糊回答，没人说死）
    重点：把「当时看起来正常」的质疑写清楚，留给结局回望

三、决定/行动（400-500字）
    功能：主角做出那个关键决定
    技巧：写出最后那个「推力」
    结尾：一个安静的、具体的行动（不是宣言）

四、过程（500-700字）
    功能：一切看起来都在推进（暗流在走）
    技巧：穿插让人放松的细节
    重点：这些细节都会在第六章被回望

五、转折（400-500字）
    功能：一切改变了
    技巧：用「地点变化」或「节奏突变」标志转折
    重点：转折时反慢镜——不慢，反而太快

六、余震（700-1000字）
    功能：主角消化，回望所有暗示
    技巧：把第二章的每个质疑重新拎出来，配上「现在才明白」的解读
    结尾：一个具体的微观物件，不给结论
```

---

## 七、标题与章节命名

### 标题规则
- 不超过10字，不解释内容，只制造悬念
- 最好是一个具体动作或状态，不是形容词

好标题：「消失」「最后一封邮件」「永夜」「那个区块」
差标题：「一个天才的孤独」「改变世界的代价」「比特币诞生的故事」

### 章节命名规则
- 2-4个字，名词或状态词，不用完整句子

好：「怀疑」「同行者」「价格」「永夜」
差：「他开始怀疑了」「遇见了同伴」「价格开始上涨」

## 八、免责声明的写法

免责声明要「出现三次」，融入文章节奏，语气是调侃而非警告：

> 「开始之前，重要的事情说很多次：本文由 AI 创作，纯属虚构性叙事，如有巧合那就是巧合。」

位置：正文开始前 + 中间某章节结尾 + 全文末尾
