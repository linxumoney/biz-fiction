# 场景模板库

## 开场模板

### 模板A：时代背景 + 人物状态 + 触发物（最常用）

```
[时代背景，一句话定位历史坐标]。
[描述大背景的混乱/变化，比喻结尾]。
[人物名][正在做什么]，[触发物出现]。
```

示例（中本聪风格）：
> 2008年10月，雷曼兄弟倒下了31天。
> 世界金融体系还在余震里，各国央行的救市公告一条接一条，像一群人在往一艘正在下沉的船上泼水。
> 某个地方，某个人，打开了一个文档。光标在空白页上闪烁。

### 模板B：「已知结局，倒叙起点」

```
多年后，[某个结果已经存在]。
但在那之前，[某一天]，[主角]只是[当时普通的状态]。
```

示例：
> 多年后，那100万枚比特币依然没有移动过，像一个永远不会被打开的保险箱。
> 但在那之前的某个冬天，他只是一个在邮件列表里等回复的陌生人。

### 模板C：微观细节开场

```
[一个具体的、小的物件或动作]。
[然后慢慢拉开，交代背景]。
```

示例：
> 光标在空白页上闪烁。
> 这已经是第73稿了。窗外，伦敦天已经亮了。

## 转折场景模板

### 「节奏骤变」转折法

顺利进行中 → 某一句话/某个动作改变一切

```
[一切看起来正常的最后一个细节]。

然后，[转折发生]。

时间并没有像[他/她]预想的那样变慢。
恰恰相反，一切都太快了——[那句话/那件事]从[某处]传来，
精确地落在[具体位置]，然后[所有声音/反应]。
```

### 「反差」转折法

从「以为自己赢了」到「发现落入网中」：

```
[顺利的细节：握手/笑声/轻松的话题]。
[主角内心：松了口气/觉得一切顺利]。

「[某句改变一切的话]。」

[主角此刻的微观反应，不直接写情绪]。
```

## 结尾模板

### 模板A：物件永存 + 人物消失（对比型）

```
[那个物件/成果]还在，[具体描述它的永久性]。
[主角]去哪儿了？
没有人知道。[他/她]本来就不想让人知道。
这是[他/她]唯一完全成功的部分。
```

示例：
> 比特币创世区块里那行字还在，嵌在区块链的最底层，永远不会消失。
> 那个打开文档的人去哪儿了？
> 没有人知道。他本来就不想让人知道。
> 这是他唯一完全成功的部分。

### 模板B：时间线轨迹 + 当下落差

```
[他/她]是[年份]生的，[出生地，越具体越好]。
[动词串联成长轨迹……]
[他/她]走了[N]年，走得很远。
现在[当下处境]。
```

### 模板C：微观镜头收尾（最克制）

```
[他/她][把某物放在某处/做了某个小动作]。
窗外，[某个景象依然如故]。
[城市/世界]什么都没有变。
变的只是[他/她]，和[他/她]再也回不去的那条路。
```

## 「多方回应」段落模板

展示各方的模糊反应，为后文回望埋伏笔：

```
[他/她]等待回复。

第一个人说：「[模糊质疑A]。」措辞[礼貌/中立]，但意思很清楚：[真实含义]。
第二个人的回复[要热情/要谨慎]一些，但[仍然充满X]。

[他/她]一一回复，耐心得像一个准备了很久的人。

每一个问题[他/她]都已经想过了。
[他/她]的答案总是比问题更深一层。
```

## 「轻松细节作为陷阱」模板

在「过程顺利」章节埋伏笔，在「余震」章节回望：

**埋伏时（第四章）：**
> 他们在邮件里聊得越来越顺，有人开始叫他「聪」，像叫一个老朋友。

**回望时（第六章）：**
> 他想起那段邮件往来里的轻松，那些技术问题讨论之外的闲聊。
> 那种轻松是真实的，又或者，正因为是真实的，才更让人觉得安全。
> 而「安全感」本身，有时候才是最大的陷阱。
